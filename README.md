# Netzwerk und Firewall: Übungen

Netzwerktechnik, WLAN, Gästenetz, VPN, Firewalls und Reverse Proxy. Alles auf Deutsch. Jeder Kurs liegt in einem eigenen Ordner und hat seine eigene README.

## Kurse

| Ordner | Art | Inhalt |
|---|---|---|
| [packet-tracer](packet-tracer/) | Übungsreihe | Netzwerktechnik mit Packet Tracer, von den Grundlagen bis Routing, Sicherheit, VPN, IPv6 und Fehlersuche |
| [wlan-gaestenetz](wlan-gaestenetz/) | Übungsreihe | WLAN und Gästenetz: VLANs, Zugriffsregeln, 802.1X |
| [vpn-mit-wireguard-und-openvpn](vpn-mit-wireguard-und-openvpn/) | Übungsreihe | VPN mit WireGuard und OpenVPN: 12 Module, 82,5 Stunden; in einer Testumgebung teilweise ausgeführt |

| [linux-firewall-mit-nftables-und-iptables](linux-firewall-mit-nftables-und-iptables/) | Übungsreihe | Linux-Firewall mit nftables und iptables: 13 Module, 79,5 Stunden; in einem Namespace-Labor ausgeführt |

## Lizenz

Die Lizenz gilt je Kursordner und steht dort in der Datei `LICENSE` (Code) bzw. `LICENSE-DOCS.md` (Texte). Der Hinweis in der README des jeweiligen Kurses nennt, welche Lizenz gilt.
