## Lernziele

Nach dieser Übung kannst du

- Sets mit Timeout und Intervallen anlegen und zur Laufzeit ändern
- eine Verdict-Map für Dienste einsetzen
- Regelwerke mit Sets verkürzen

## Voraussetzungen

- Modul 3

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| Set | benannte Menge von Adressen, Ports oder Verkettungen, die in Regeln mit `@name` verwendet wird |
| Verdict-Map | Map, die einem Wert eine Entscheidung (accept, drop, jump) zuordnet |
| Timeout | Lebensdauer eines Elements; es verschwindet von selbst |
| Verkettung | Elemente aus mehreren Feldern, z. B. Adresse und Port |

## Aufgabe

### Aufgabe 1 – Set mit Timeout (Einheit 5.1)

Laden Sie `sets_maps.nft` auf `srv01`. Sperren Sie den Client mit `nft add element … gesperrt { 10.0.1.2 timeout 5m }` und zeigen Sie die Wirkung und den Rest-Timeout.

### Aufgabe 2 – Intervall-Set (Einheit 5.1)

Entfernen Sie das Client-Netz aus dem Set `intern` und erklären Sie die Wirkung auf Port 8080.

### Aufgabe 3 – Verdict-Map (Einheit 5.2)

Fügen Sie der Map `dienste` den Port 443 mit `accept` hinzu und erklären Sie den Vorteil gegenüber drei Einzelregeln.

### Aufgabe 4 – Skript auswerten (Einheit 5.3)

Führen Sie `bash sets_demo.sh` aus und erklären Sie jede der sechs Ausgaben.

### Aufgabe 5 – Entscheidung (Einheit 5.4)

Nennen Sie zwei Fälle, in denen ein Set sinnvoll ist, und einen, in dem eine Einzelregel reicht.

## Hinweise

- Zur Laufzeit hinzugefügte Elemente stehen nicht in der Datei und gehen beim Neuladen verloren.
- Das Set `intern` wird in der Kette `verwaltung` verwendet; die Map ruft diese Kette für Port 8080 auf.
- Der Verdict `jump verwaltung` geht in eine reguläre Kette, die mit `drop` endet.

## Kontrollfragen

1. Wozu dient das Flag `timeout` bei einem Set?
2. Was ist eine Verkettung `ipv4_addr . inet_service`?
3. Was ist eine Verdict-Map?
4. Was gilt für Elemente, die Sie zur Laufzeit hinzufügen, nach einem Neuladen der Datei?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

1. Siehe `beispiele/sets_demo.ausgabe.txt`: nach dem Eintrag Port 80 blockiert, nach dem Löschen wieder OK; der Timeout läuft mit.
2. Ohne 10.0.1.0/24 greift in `verwaltung` das `drop`: Port 8080 blockiert.
3. `nft add element inet filter dienste { 443 : accept }`.
4. Siehe Ausgabe.
5. Sinnvoll: viele Adressen sperren (Blocklist), Dienste-Tabelle; Einzelregel: ein einziger Port.

**Kontrollfragen (Antwortskizzen):**

1. Die Elemente verfallen nach der angegebenen Zeit automatisch, nützlich für temporäre Sperren.
2. Ein Element aus Adresse und Port gemeinsam (z. B. 10.0.1.2 . 8080).
3. Eine Map, die einem Wert (z. B. Port) eine Entscheidung zuordnet (accept, drop, jump …).
4. Sie gehen verloren; nur was in der Datei steht, wird wiederhergestellt.

</details>
