
## 1. LAN -> SERVER
ping 10.0.2.2: OK
http 10.0.2.2:80: OK
http 10.0.2.2:8080: OK

## 2. Nicht erlaubter Port (22 über eine Test-Verbindung)
22: keine Verbindung (verworfen oder kein Dienst)

## 3. SERVER -> LAN (muss verworfen werden)
ping 10.0.1.2: keine Antwort
srv->lan http: BLOCKIERT

## 4. Firewall selbst: Ping aus LAN erlaubt, Ping aus SERVER-Zone nicht
ping 10.0.1.1: OK
ping 10.0.2.1: keine Antwort

## 5. Zähler der Ketten
table inet fw {
	chain lan_zu_srv {
		tcp dport @web_ports counter packets 2 bytes 120 accept
		icmp type echo-request counter packets 1 bytes 84 accept
	}
}
table inet fw {
	chain srv_zu_lan {
		counter packets 3 bytes 204 drop
	}
}
