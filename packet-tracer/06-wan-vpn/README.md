# Modul 6: WAN und VPN

Teil der Übungsreihe [Netzwerktechnik mit Cisco Packet Tracer](../README.md).

## Beschreibung

Das Modul behandelt die Kopplung von Standorten über Weitverkehrsnetze und die Absicherung dieser Verbindungen.

## Ziele

- Standorte über WAN-Strecken verbinden
- Tunnel (GRE) und das Prinzip eines VPN (IPsec) verstehen
- Eine Standortkopplung planen und konfigurieren
