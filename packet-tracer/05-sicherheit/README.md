# Modul 5: Sicherheit

Teil der Übungsreihe [Netzwerktechnik mit Cisco Packet Tracer](../README.md).

## Beschreibung

Das Modul zeigt grundlegende Absicherung von Geräten und Netzen: sicherer Fernzugriff, Schutz der Switch-Ports und Filterung von Verkehr.

## Ziele

- Geräte grundlegend absichern und per SSH sicher verwalten
- Switch-Ports mit Port Security absichern
- Zugriffslisten (ACLs) planen und einsetzen
