# Modul 8: Fehlersuche

Teil der Übungsreihe [Netzwerktechnik mit Cisco Packet Tracer](../README.md).

## Beschreibung

Das Modul besteht aus Aufgaben mit eingebauten Fehlern. Das Netz ist bereits aufgebaut, aber es funktioniert nicht; die Ursache muss systematisch gefunden werden.

## Ziele

- Fehler schrittweise eingrenzen, von der Verkabelung bis zur Konfiguration
- Prüfbefehle gezielt einsetzen
- Eine Vorgehensweise für die Fehlersuche entwickeln

## Hinweise

- Jede Übung beschreibt jeden Schritt über die GUI und über die CLI. Alle Befehle stehen in Codeblöcken.
- Die Musterlösung nennt jeweils die eingebauten Fehler und den Weg zu ihrer Entdeckung.
- Dialog-Modus: Schreibe „Gib mir eine Störung für Modul X“, dann erhältst du nur die Symptome und suchst die Ursache selbst.
- Setzt die Module 1 bis 5 voraus.
