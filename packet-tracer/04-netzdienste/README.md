# Modul 4: Netzdienste

Teil der Übungsreihe [Netzwerktechnik mit Cisco Packet Tracer](../README.md).

## Beschreibung

Das Modul behandelt Dienste, die ein Netz im Alltag benutzbar machen: automatische Adressvergabe, Namensauflösung und Adressumsetzung zum Internet.

## Ziele

- DHCP einrichten und Leases nachvollziehen
- DHCP-Relay über Netzgrenzen einrichten
- DNS-Auflösung konfigurieren und testen
- NAT und PAT erklären und einrichten
