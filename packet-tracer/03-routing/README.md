# Modul 3: Routing

Teil der Übungsreihe [Netzwerktechnik mit Cisco Packet Tracer](../README.md).

## Beschreibung

Das Modul zeigt, wie Datenpakete zwischen verschiedenen Netzen ihren Weg finden: von festen Routen bis zum dynamischen Routing-Protokoll OSPF.

## Ziele

- Statische Routen planen und konfigurieren
- Kommunikation zwischen VLANs einrichten (Inter-VLAN-Routing)
- OSPF konfigurieren und die Routing-Tabelle lesen
