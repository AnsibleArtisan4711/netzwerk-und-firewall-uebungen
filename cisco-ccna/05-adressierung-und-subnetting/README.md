# 05 Adressierung

Übung **05.1** (Priorität 1). Geschätzte Zeit: 6 bis 8 Stunden (Schätzung; Lehrplan: 10 UE zu 45 Minuten = 7,5 Stunden).

> Skripte im Container ausgeführt (Ubuntu 24.04.5); keine Cisco-Geräte, kein Packet Tracer, Hyper-V-Labor nicht aufgebaut.
